# LinkShortener

Консольное приложение для сокращения ссылок с поддержкой TTL, лимита переходов, мультипользовательского режима и прав доступа.

## Требования

- JDK 24
- Maven 3.9+

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/natalia0mareeva/LinkShortener.git
   cd LinkShortener
   
2. Соберите проект и запустите тесты:
   ```bash
   mvn clean test

3. Запустите приложение:
   ```bash
   mvn compile exec:java -Dexec.mainClass="org.example.Main"

## Команды
 | Команда	  |Описание|
 |---------|----------|
 |1|Создать новую короткую ссылку|
 |2|Перейти по короткой ссылке (редирект)|
 |3|Показать все мои ссылки|
 |4|Удалить ссылку (только владелец)|
 |5|Изменить лимит переходов (только владелец)|
 |0|Выход|

## Архитектура
```text
org.example
- Main               — точка входа
- core
   - Link           — модель ссылки
   - LinkService    — бизнес-логика (создание, редирект, права, TTL)
- infra
   - ConfigLoader   — чтение config.properties
- ui
   - ConsoleUI      — консольный интерфейс
```

## Принципы:
- Слоистость: core не зависит от infra/UI.
- DI: сервисы передаются через конструктор.
- Concurrency: используется ConcurrentHashMap для потокобезопасности.

## Конфигурация
Параметры хранятся в src/main/resources/config.properties:
default.ttl.minutes=60
default.max.clicks=10

## Тестирование
Проект покрыт unit-тестами (JUnit 5). Запуск:
```"bash
mvn test
```

Тесты проверяют:
- Уникальность коротких кодов
- Инкремент счетчика переходов
- Блокировку по лимиту
- Истечение TTL
- Проверку прав (владелец/чужой)
- Мультипользовательский режим

## CI/CD
GitHub Actions автоматически собирает проект и запускает тесты при каждом push (см. .github/workflows/maven.yml).
